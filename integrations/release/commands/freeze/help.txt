Usage: wi-impl release freeze <RELEASE_NAME> [flags]

Record a production snapshot for a release.

Production cannot be queried directly, so its state is captured indirectly:
each item's current STAGE position is frozen into the ledger as the prod
pointer. Run this right after the release is pushed to production.

Requires that `wi-impl release matrix` has already been run for this release
(it writes the release record this command reads).

WRITES LOCAL STATE: ~/.wi-impl/promotion/prod-snapshots/<name>.json (atomic).
An existing snapshot is kept unless --force (SNAPSHOT_EXISTS). Items with no
stage data (stage not traced, or a trace error) are recorded as "unknown" with
a warning; if no item has stage data, nothing is written
(FREEZE_NO_STAGE_DATA). A corrupt release record is LEDGER_CORRUPT.

Arguments:
  <RELEASE_NAME>        Name of a release previously audited with
                        `wi-impl release matrix` (the `name` field of its spec).

Flags:
  --force               Replace an existing prod snapshot for this release.
  --help, -h            Show this help message.

Global Flags:
  --llm                 Output structured JSON envelope for scripting/LLM use.

Examples:
  wi-impl release freeze may-12-release
  wi-impl release freeze may-12-release --force
