Usage: wi-impl release matrix <release.json> [flags]

Audit a production release. Given a spec of included and excluded tickets, it
links each ticket to its AD/PD items (via `tw items`), traces every AD item
across all environments (via `ad trace`), and reports collisions and leaks.

A COLLISION is an AD method touched by BOTH an included and an excluded
ticket — shipping the included ticket would drag the excluded ticket's edits
along. For each collision it reports a LEAK status: whether the excluded
change has already reached the stage environment.

Items per ticket: an EXCLUDED ticket contributes every AD reference in its
comments (a single plain AD URL counts). An INCLUDED ticket uses its latest
dev-note block, or every AD reference when no block lists AD items.

If any ticket cannot be linked (Teamwork error, not found), the audit fails
with RELEASE_MATRIX_INCOMPLETE: collisions are unknown and nothing is saved.

WRITES LOCAL STATE: the result is saved to the promotion ledger
(~/.wi-impl/promotion/releases/<name>.json, atomic write), replacing the previous
audit of the same release. A different release name that maps to the same
file is refused (LEDGER_NAME_COLLISION).

release.json format:
  {
    "name": "may-12-release",
    "included": [26917411, "https://.../tasks/26920000"],
    "excluded": [26918000],    (optional, default [])
    "project": "ACME",         (optional)
    "spineEnv": "acme-dev",    (optional)
    "stageEnv": "acme-stage"   (optional)
  }

The spec is validated before any request (BAD_SPEC; shape problems are listed together):
unknown keys, a name without letters/digits, an empty "included", junk
ticket refs, a ticket both included and excluded, unconfigured envs,
spineEnv and stageEnv from different projects.

spineEnv/stageEnv default to the project's "<project>-dev" / "<project>-stage"
envs. The project is "project", else that of an explicit spineEnv/stageEnv,
else that of the active env (--env / WI_IMPL_ENV / defaultEnv).

Arguments:
  <release.json>        Path to the release spec JSON file.

Flags:
  --help, -h            Show this help message.

Global Flags:
  --llm                 Output structured JSON envelope for scripting/LLM use.

Notes:
  - AD-only: PD items are listed per ticket but not yet traced across envs.
  - Traces run sequentially (the tracer mutates the active env), so a large
    release can take a few minutes.

Examples:
  wi-impl release matrix ./may-12.json
  wi-impl release matrix ./release.json --env acme-dev --llm
