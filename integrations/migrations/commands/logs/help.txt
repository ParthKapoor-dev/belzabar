Usage: wi-impl migrate logs <buildNumber> [flags]

Print the full console output of a Jenkins migration build.

DESCRIPTION
  Fetches /job/<job>/<n>/consoleText, strips ANSI escapes, and prints it.

ARGUMENTS
  <buildNumber>       Jenkins build number (digits only).

FLAGS
  --llm               Emit structured JSON for agent consumption.
  --help, -h          Show this help message.

EXAMPLES
  wi-impl migrate logs 743
  wi-impl migrate logs 743 --llm
