Usage: wi-impl migrate status <buildNumber> [flags]

Check a Jenkins migration build's status, result, and parameters.

ARGUMENTS
  <buildNumber>       Jenkins build number (digits only).

FLAGS
  --llm               Emit structured JSON for agent consumption.
  --help, -h          Show this help message.

EXAMPLES
  wi-impl migrate status 743
  wi-impl migrate status 743 --llm
