Usage: wi-impl pd find-ad-methods <INPUT> [flags]

List all Automation Designer method IDs referenced in a page or component
(the AD methods its HTTP calls execute).

Arguments:
  <INPUT>             Page/component id, exact page or component name, or a
                      PD / app URL (resolved like `wi-impl pd show`).

Flags:
  --component         Treat a name <INPUT> as a component name only.
  --recursive, -r     Also scan every component the layout references,
                      recursively. Components that cannot be resolved are
                      listed in `errors` (and warned about).
  --force             Bypass the local config cache (the root and, with
                      --recursive, every referenced component). data.cache
                      counts cached vs fresh reads.
  --help, -h          Show this help message.

Global Flags:
  --env <name>        Set active environment.
  --llm               Output structured JSON envelope for scripting/LLM use.

Examples:
  wi-impl pd find-ad-methods 49fa2576239ec5791c6ead4cf9408ce2
  wi-impl pd find-ad-methods n_s_staff_email_correspondence --component
  wi-impl pd find-ad-methods 49fa2576239ec5791c6ead4cf9408ce2 --recursive --llm
