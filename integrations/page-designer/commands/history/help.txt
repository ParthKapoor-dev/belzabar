Usage: belz pd history <action> <pageId> [flags]

Browse and restore previous versions of a PD page. Backed by the server-
side history service at /rest/api/pagedesigner/pages/history.

Actions:
  list <pageId>                        List every saved version of the page.
  show <pageId> --version <vid>        Parse + validate one historical version.
  diff <pageId> --from A --to B        Structural diff between two versions
                                       (variables, derived, http, layout
                                       nodes, styles, other config keys).
  restore <pageId> --version <vid>     Copy the version into the page's
                                       DRAFT (PUT /pages/revert/<draftId>
                                       ?versionId=<vid>). The published page
                                       is untouched: publish to make it live.
                                       Locks the draft, validates the version
                                       against a fresh read (diff-aware) and
                                       reads the draft back (data.verify;
                                       PD_RESTORE_VERIFY_FAILED on mismatch).

Flags:
  --version <vid>       Version id (for show / restore).
  --from <A>            First version id (for diff).
  --to <B>              Second version id (for diff).
  --limit <N>           Cap "list" rows (default 50; list only).
  --yes, -y             Confirm the restore (required with --llm or without a
                        terminal; otherwise belz asks).
  --force-validation    Restore despite validator errors the version introduces.
  --help, -h            Show this help message.

Global Flags:
  --env <name>          Environment (default: WI_IMPL_ENV, else defaultEnv, else the only env). restore is
                        a write and needs it explicitly.
  --llm                 Output structured JSON envelope.

Notes:
  • Version ids are global. show / diff / restore refuse a version that does
    not belong to <pageId> or its linked sibling (PD_VERSION_PAGE_MISMATCH).
  • History is recorded on the PUBLISHED page: a draft id usually lists 0
    versions — list the published id (`belz pd show <draftId>` names it).
  • list returns metadata only — use show for full config.
  • diff compares structure, not line-by-line JSON.
  • restore rewrites the DRAFT only (verified live); a page with no linked
    draft is refused (PD_PUBLISHED_NO_DRAFT). belz never reverts the
    PUBLISHED row: the server would overwrite the live page without a
    publish or history entry, and flip that row to DRAFT.

Examples:
  belz pd history list 4bde22f76091a82364fda322eeeda597
  belz pd history show 4bde22f76091a82364fda322eeeda597 --version 378840
  belz pd history diff 4bde22f76091a82364fda322eeeda597 --from 375333 --to 378840
  belz pd history restore 4bde22f76091a82364fda322eeeda597 --version 375333 --yes
  belz pd history list 4bde22f76091a82364fda322eeeda597 --limit 10 --llm | jq '.data.versions'
