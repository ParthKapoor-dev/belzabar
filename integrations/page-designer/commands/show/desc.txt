wi-impl pd show <input>  :->  A page or component by id, exact name or URL: name, ids, variable/HTTP/component counts
wi-impl pd show <input> --vars  :->  List all user-defined and derived variables (compact rows: name, type, short initialValue; derived: from, sideEffect)
wi-impl pd show <input> --vars --fields <a,b,…|all>  :->  Pick the --vars/--http row fields (e.g. name,spec) or all
wi-impl pd show <input> --find <text|id|component>  :->  Find layout nodes: id, component, label, key path, parentId/index (for node-id overlay ops)
wi-impl pd show <input> --http  :->  List all HTTP service calls with AD IDs and triggers
wi-impl pd show <input> --components  :->  Show the layout tree, one line per node (name#id [sym] [ev])
wi-impl pd show <input> --var-detail <name>  :->  Show full config for a specific variable or derived (spec code, dependencies)
wi-impl pd show <input> --http-detail <N>  :->  Show full config for the Nth HTTP call (input bindings, handlers, transform code)
wi-impl pd show <input> --full  :->  Show all sections and all details
wi-impl pd show <input> --force  :->  Bypass the local cache (SWR 5 min soft / 1 h hard) and fetch fresh config
wi-impl pd show <input> --raw  :->  Include raw configuration JSON and source API fields
wi-impl pd show <input> --recursive  :->  Include recursive component dependency tree and all AD method IDs (-r)
wi-impl pd show <input> --tree  :->  Full layout tree with node-kind badges and inline pitfall markers
wi-impl pd show <input> --node <id>  :->  Kind-specific detail for a single node (bindings, validations, events)
wi-impl pd show <input> --var-graph  :->  Per-variable write/read/derive/trigger map; flags dead variables
wi-impl pd show <input> --open  :->  Open the editable draft/symbol in the browser (-o)
