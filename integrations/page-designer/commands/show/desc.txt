belz pd show <input>  :->  Display overview of a page or component (name, IDs, variable/HTTP/component counts)
belz pd show <input> --vars  :->  List all user-defined and derived variables (compact rows: name, type, short initialValue; derived: from, sideEffect)
belz pd show <input> --vars --fields <a,b,…|all>  :->  Pick the --vars/--http row fields (e.g. name,spec) or all
belz pd show <input> --find <text|id|component>  :->  Find layout nodes: id, component, label, key path, parentId/index (for node-id overlay ops)
belz pd show <input> --http  :->  List all HTTP service calls with AD IDs and triggers
belz pd show <input> --components  :->  Show the layout tree, one line per node (name#id [sym] [ev])
belz pd show <input> --var-detail <name>  :->  Show full config for a specific variable or derived (spec code, dependencies)
belz pd show <input> --http-detail <N>  :->  Show full config for the Nth HTTP call (input bindings, handlers, transform code)
belz pd show <input> --full  :->  Show all sections and all details
belz pd show <input> --force  :->  Bypass the local cache (SWR 5 min soft / 1 h hard) and fetch fresh config
belz pd show <input> --raw  :->  Include raw configuration JSON and source API fields
belz pd show <input> --recursive  :->  Include recursive component dependency tree and all AD method IDs (-r)
belz pd show <input> --tree  :->  Full layout tree with node-kind badges and inline pitfall markers
belz pd show <input> --node <id>  :->  Kind-specific detail for a single node (bindings, validations, events)
belz pd show <input> --var-graph  :->  Per-variable write/read/derive/trigger map; flags dead variables
belz pd show <input> --open  :->  Open the editable draft/symbol in the browser (-o)
