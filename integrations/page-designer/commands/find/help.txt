Usage: belz pd find [query] [flags]
       belz pd find list [--components]
       belz pd find pick [query] [flags]

Search for pages and components in the Page Designer.
The index is cached locally for 7 days; use --refresh to rebuild.

Arguments:
  [query]             Search term (name, route, or ID). Omit to browse.

Subcommands:
  list                List all pages (add --components for components; a
                      component's draft/published pair is one row).
  pick                Interactive fuzzy picker (requires fzf).

Flags:
  --type page|component  Restrict results to one entity type.
  --refresh           Rebuild the index from the API.
  --limit <N>         Max rows (search default 20; list default all; max
                      1000). totalMatches / total report the count before it.
  --open              Open selected item in browser (pick mode only).
  --components        With `list`: list components instead of pages.
  --full              Full rows (url, updatedAt) and cache metadata. By
                      default rows are id, referenceId, name, route/status
                      (+ type, score in search).
  --llm               Output structured JSON envelope.

Global Flags:
  --env <name>        Set active environment.

Examples:
  belz pd find notice
  belz pd find notice --type page
  belz pd find list
  belz pd find list --components
  belz pd find list --limit 50
  belz pd find list --full --llm
  belz pd find pick
  belz pd find pick LT-260 --open
  belz pd find --refresh
