Usage: wi-impl ad categories [flags]

List all AD categories (services) — both user-generated and system-generated.
ID is the chain-category id (what methods, `ad find` and `ad export-category`
use); System ID identifies the automation system behind it.
SYSTEM_GENERATED services have no chain category (ID is empty). UUIDs are trimmed.

Flags:
  --user              Only show USER_GENERATED categories
  --system            Only show SYSTEM_GENERATED categories (cannot be combined with --user)
  --search <text>     Only categories whose name or label contains <text>
                      (case-insensitive), or whose id / uuid is <text>.
  --fields <a,b|all>  Pick row fields: id,uuid,name,type,systemId,systemUuid,
                      chainCategoryId,chainCategoryUuid,label; `all` = full
                      rows. Default: id, uuid, name, type, systemId (empty
                      values omitted).
  --help, -h          Show this help message.

Global Flags:
  --env <name>        Set active environment (default: WI_IMPL_ENV, else defaultEnv, else the only env).
                      Any env from `wi-impl envs` (configured in ~/.wi-impl/config.json).
  --llm               Output structured JSON envelope for scripting/LLM use.

To list the methods in a category, use `wi-impl ad find` with a category (see
`wi-impl ad find --help`).

Examples:
  wi-impl ad categories --user
  wi-impl ad categories --search sandbox --env acme-dev --llm
  wi-impl ad categories --fields name,systemUuid --llm
  wi-impl ad categories --llm | jq '.data.categories[] | select(.type == "SYSTEM_GENERATED")'
