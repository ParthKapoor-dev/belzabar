Usage: wi-impl ad show <UUID|URL|FILE> [flags]

Display the structure and metadata of an Automation Designer method.
The default view caches the parsed method (up to 1 hour). A cached copy is
only served after one cheap read confirms the server still has its version;
when the server is ahead, the method is read fresh and a warning names both
versions. `data.cache` {savedAt, ageMinutes, version, serverVersion} says which
cached copy was served. --force, --step N, --compact and --story always read
fresh.
A local V2 (steps[]) or V1 method JSON file is shown without any fetch — use it
with --story to present a method for approval before `ad create` / `ad save`.

The default step table has a Gates column: entry condition (`when`), loop,
conditional exit (`exit-if <expr> → <code>`: the method returns after the
step when it holds), `exit-on-fail`, `async` and the step's account. Step
detail (--service-detail / --full) adds "Exit If", the exit code/message and
"Account"; the header shows Deprecated / Scope / Timeout when set. Conditions
and exit conditions are never cut; any other cut text ends `…(+N, use --full)`.

`summary.summary` is the method's summary as stored ("" when none; never the
description) and `summary.methodDescription` its long description (the
`ad save` key `description`). --compact has `summary` / `methodDescription`;
--story shows "What it does" (summary) and "Description (methodDescription)".
Input and variable default values are shown everywhere the fields are:
`defaultValue` (and V1 `testValue`, kept apart) with --inputs / --variables,
`defaults {inputs, variables}` in --compact, a Default column in --story.
A method with no steps (a built-in service) shows its inputs and outputs
without flags, with a `note`.

The --llm payload is lean: no request echo, empty/null fields dropped, SQL and
code bodies only when asked for (--sql / --code / --full / --service-detail),
and the wire body only with --raw (emitted once, as `raw`).

Arguments:
  <UUID|URL|FILE>         The UUID of the method, a full AD URL
                          (e.g. https://dev.example.test/automation-designer/Category/426f97...),
                          or the path of a local method JSON file.

Flags:
  --compact               One line per step: index, kind/service, description,
                          (kind SPEL is a Helpers.Legacy/echo step: it evaluates
                          its Input as SpEL and always returns text),
                          entry condition, loop, decoded SQL/code/SpEL (cut at
                          160 chars), key inputs, outputs -> variables, exit
                          rules (exit-on-fail, exit-if), async, account. Add --sql / --code for full bodies (`blocks`,
                          always present, `[]` when there are none, once
                          asked for), --full for no abbreviation, --step <N>
                          for one step, whole. Service calls are also listed
                          in `callees` {step, category, categoryUuid, method,
                          apiUuid}; categories use their canonical name (an
                          alias such as `A - B` is resolved through the cached
                          `ad find` index when there is one).
                          Always read fresh from the V2 route, so input paths
                          (`body.json=`) and outputs (`key→as⇒$var`) use the
                          keys that `ad save` ops and create specs accept.
  --story                 The plain-English approval template (What it does,
                          Approach, Service, Inputs / Outputs / Steps tables,
                          decoded custom code and SQL) as Markdown. Read fresh
                          from the V2 route, like --compact.
  --inputs                Show a table of input arguments.
  --outputs               Show the method's outputs.
  --variables             Show the method's variables.
  --services              Show a list of service steps.
  --service-detail <N>    Only the step with orderIndex N (1-based, as listed
  --step <N>              by --services), read fresh: `stepDetail` with its
                          body (SQL / source / expression) and bound inputs;
                          no `steps` list. Aliases.
  --version <N>           Show saved version N of this chain (draft or
                          published history, by the uuid's side) instead of
                          the current one; works with every view. `source:
                          "history"` and `history` {version, side, addedBy,
                          addedWhen, isPublished}. Not with --force.
  --code                  Include decoded custom-code source in step detail.
  --sql                   Include SQL text in step detail.
  --full                  Include expanded per-service logic details; with
                          --compact / --story nothing is cut.
  --force                 Bypass cache and fetch a fresh method definition.
  --raw                   Include the wire body (V1 or V2, as fetched) once.
  --open, -o              Open the editable draft URL in your default browser
                          (uses the draft uuid even when the input is the
                          published id).
  --v2                    Fetch through the V2 API.
  --help, -h              Show this help message.

Global Flags:
  --env <name>            Set active environment (default: WI_IMPL_ENV, else defaultEnv, else the only env).
                          Any env from `wi-impl envs` (configured in ~/.wi-impl/config.json).
  --llm                   Output structured JSON envelope for scripting/LLM use.

Errors: METHOD_NOT_FOUND for an unknown uuid, and for a soft-deleted method
(details.deleted: true): the V1 route still serves deleted records, so a V1
read also reads V2, and a cached copy of a method since seen deleted is refused.

Examples:
  wi-impl ad show 1234-5678 --compact --llm
  wi-impl ad show 1234-5678 --compact --sql
  wi-impl ad show ./new-method.json --story
  wi-impl ad show 1234-5678 --services
  wi-impl ad show 1234-5678 --service-detail 2
  wi-impl ad show 1234-5678 --version 45 --compact
  wi-impl ad show 1234-5678 --raw --llm
  wi-impl ad show 1234-5678 --open
