wi-impl ad history <uuid>  :->  List all saved versions of the chain the uuid names (same as list; draft and published histories are separate; addedWhen ISO UTC; historyEmpty + updatedOn when there are none)
wi-impl ad history list <uuid>  :->  List all saved versions of the chain the uuid names (draft and published histories are separate)
wi-impl ad history show <uuid> --version <N>  :->  Fetch and parse one saved version
wi-impl ad history show <uuid> --version <N> --full  :->  Also return the full parsed method at that version
wi-impl ad history show <uuid> --version <N> --sql --code  :->  Whole SQL / code bodies as blocks, the same shape as the ad show compact view
wi-impl ad history diff <uuid> --from <N> --to <M>  :->  Compare two versions (steps, kinds, inputs; a line diff of each changed SQL/code/SpEL body; id/encoding-only changes ignored)
wi-impl ad history restore <draftUuid> --version <N> --env <env> [--yes]  :->  Revert the draft to a previous draft version (write; draft-guarded, confirms first, reports resultingVersion)
wi-impl ad history restore <draftUuid> --version <N> --env <env> --keep-case-changes  :->  Keep the test cases the restore brought back (default: the current cases are put back; data.testCases)
