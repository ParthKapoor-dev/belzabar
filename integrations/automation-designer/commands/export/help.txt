Usage: wi-impl ad export <method-id-or-uuid> [flags]

Export a single method via /rest/api/automation/chain/export/{id}. A uuid
(any spelling, or an AD URL) is resolved to the numeric chain id first.

Flags:
  --out <file>    Write the exported JSON to a file; the envelope then carries
                  only {id, uuid, writtenTo, bytes, methods} (no body).
  --full          With --out: also include the body (`preview`) in the output.
  --llm           Emit a JSON envelope with {env, id, uuid, writtenTo, bytes, methods, preview}

Without --env the default env is used, never silently: `data.env` names it,
and a warning (meta.warnings; stderr in human mode) says it was the default.

Examples:
  wi-impl ad export 98765 --out /tmp/method.json
  wi-impl ad export 4bf56e008eabe4010508af439a15ecfb --llm
