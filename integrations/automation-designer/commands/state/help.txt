Usage: belz ad state <uuid> [flags]

Print draft/published linkage, versions, and whether the draft has unpublished changes.

Flags:
  --llm    Emit a JSON envelope with {draftUuid, publishedUuid, state, versions,
           fingerprints, inSync}

Notes:
  - Wraps lib/draft-guard.ts:resolveDraftTarget() and is the safe read-only
    way to inspect draft/published state before calling any write command.
  - inSync compares the behaviour fingerprints (lib/fingerprint.ts: the whole
    body minus ids, versions, stamps, changelogs and testSuite — so outputs,
    loops, exits, async, accounts, variables all count) of the draft
    and the published body, both read on V2 (V1 bodies carry UI noise that
    differs between the two copies; uuids count normalised, numeric ids not):
    true = identical, false = the draft has unpublished changes, null = never
    published. The draft and published version counters are independent, so
    versions.draft > versions.published does not mean out of sync.
  - Exit code is 0 even when the method is PUBLISHED without a linked draft;
    the envelope `ok` field surfaces the distinction.

Example:
  belz ad state 4a1b2c3d... --llm | jq '.data'
