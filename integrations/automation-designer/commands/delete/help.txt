Usage: belz ad delete <UUID> --env <env> [flags]

Soft-delete an unpublished DRAFT method (DELETE /chain/v2/{uuid}). The
platform keeps the record (V1 still returns it); it no longer reads on V2 and
no longer runs.

Only a DRAFT that was never published can be deleted:
  - PUBLISHED method                → AD_DELETE_PUBLISHED
  - DRAFT with a published version  → AD_DELETE_HAS_PUBLISHED
  - state missing                   → AD_DRAFT_GUARD_STATE_UNKNOWN (fail closed)
  - unknown or already deleted      → METHOD_NOT_FOUND

Arguments:
  <UUID>                Draft uuid (any spelling) or AD URL.

Flags:
  --yes, -y             Skip the confirmation prompt (required with --llm).
  --v2                  Accepted for consistency (delete always uses V2).
  --help, -h            Show this help message.

Global Flags:
  --env <name>          Set active environment. Required: delete is a write.
  --llm                 Output structured JSON envelope for scripting/LLM use.

Data: {uuid, name, deleted, verified} — verified = the V2 re-read no longer
finds the method. Local and compiled caches are evicted.

Examples:
  belz ad delete 4a1b2c3d... --env <env>
  belz ad delete 4a1b2c3d... --env <env> --yes --llm
