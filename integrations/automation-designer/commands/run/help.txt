Usage: wi-impl ad run <PUBLISHED_ID> [PAYLOAD] [flags]

Execute a published Automation Designer method. This has real side effects,
so an explicit --env is required.

A uuid runs its OWN saved body: a DRAFT uuid runs the draft (unpublished
changes included), not its published copy. wi-impl warns and reports
inputState/publishedUuid; pass the published uuid to run what is published.
data.ranVersion names the copy that ran (PUBLISHED v47). A PUBLISHED uuid
whose draft has unpublished changes is warned about, and so is every method
a step calls whose draft has unpublished changes (a call always runs the
callee's PUBLISHED copy).

Arguments:
  <PUBLISHED_ID>      The unique ID of the published method version.
  [PAYLOAD]           JSON string or path to a JSON file. Defaults to '{}' if omitted.
                      Text starting with { or [ is always read as JSON (any
                      length), never as a file name.

Flags:
  --raw               Include raw payload in output.
  --repeat <N>        Run N times (1-100) and report data.repeat {runs,
                      serverMs, wallMs}, each {min, median, max, values[]}
                      (serverMs from executionStatus.totalExecutionTime); the
                      response is the first run's. N real executions:
                      confirms (--yes with --llm). Not with --stream.
  --yes, -y           Confirm the --repeat runs.
  --stream            Opt into a streaming method: sends
                      Accept: application/stream+json. If the method streams,
                      progressive chunks are shown and the final JSON envelope
                      is parsed out separately (responseFormat="stream").
                      Non-streaming methods are unaffected.
  --help, -h          Show this help message.

Global Flags:
  --env <name>        Set active environment. Required explicitly: this
                      really executes the chain. Any env from `wi-impl envs`.
  --llm               Output structured JSON envelope for scripting/LLM use.

Notes:
  - Posts the payload to /rest/api/automation/chain/execute/<id>?encrypted=true
    with the raw session token (no Bearer prefix).
  - The output is redacted like `ad test`: credentials (a file link's
    ?token=…, Bearer/auth headers, JWTs) read [REDACTED], so a saved run
    never holds a working login.
  - A non-2xx answer fails EXECUTION_FAILED. The message names the status,
    the failing step and the method's own message ("Execution failed (403)
    at step 1: denied"); details = {path, status, body, step?,
    methodMessage?, bodyFile?}. body is parsed and redacted, JSON text
    inside it decoded into objects. A body over 16 KB is written whole
    (redacted) to ~/.wi-impl/logs/errors/ and bodyFile names the file
    (body is then a summary).
  - Without --stream the call times out after 10 minutes; with --stream it
    stays open for as long as the method runs.

Examples:
  wi-impl ad run 40ba5566efa95b033ef7af8f7f30ee09 --env <env>
  wi-impl ad run 40ba5566efa95b033ef7af8f7f30ee09 '{"type":"LT262A"}' --env <env>
  wi-impl ad run 40ba5566efa95b033ef7af8f7f30ee09 ./data/payload.json --env <env> --raw --llm
  wi-impl ad run 40ba5566efa95b033ef7af8f7f30ee09 '{"q":"hello"}' --env <env> --stream
  wi-impl ad run 40ba5566efa95b033ef7af8f7f30ee09 ./data/payload.json --env <env> --repeat 5 --yes
