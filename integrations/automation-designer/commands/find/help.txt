Usage: wi-impl ad find [LIST|PICK|QUERY] [flags]

Find Automation Designer methods and categories from a cached local index.
With no query (or `LIST`), lists all categories with method counts; add
`--category <name|id|uuid>` to list the METHODS in that category.
Rows are compact (name, alias, category, state, uuid, referenceId, apiUuid =
the automationAPIId other methods' steps use, summary, score); empty fields
are omitted.

Arguments:
  [LIST|PICK|QUERY]   LIST shows category counts.
                      PICK opens an interactive fzf picker.
                      QUERY runs ranked search over methods and categories.

Flags:
  --describe          Search method summaries / descriptions (plus name, alias,
                      category) for the QUERY words — "is there already a
                      method that does X?". Rows add `matched` words. Needs
                      index schema 2 (an older cached index is rebuilt once).
  --category <ref>    Only categories whose name starts with <ref>, or whose
                      chain-category id / uuid is <ref> (e.g. Helpers, 42).
                      Without a query: lists that category's methods
                      (data.methods, totalMethods; capped at --limit). Also
                      scopes --raw, --describe and pick.
  --fields <a,b|all>  Pick row fields: type,name,alias,category,state,uuid,
                      referenceId,apiUuid,summary,description,version,
                      categoryUuid,createdOn,updatedOn,url,score,matched
                      (categories: name,id,uuid,systemUuid,label,aliases,
                      methods); `all` = every field.
  --refresh           Rebuild method index from API before searching (progress on stderr).
  --limit <N>         Maximum matches (and --raw index rows) to return, 1-200;
                      totalMatches still counts every match. (default: 20)
  --open              Open selected method URL in browser. (pick mode only)
  --raw               Include the raw cached index (only --category's part when
                      given), capped at --limit methods/categories.
  --help, -h          Show this help message.

Global Flags:
  --env <name>        Set active environment (default: WI_IMPL_ENV, else defaultEnv, else the only env).
                      Any env from `wi-impl envs` (configured in ~/.wi-impl/config.json).
  --llm               Output structured JSON envelope for scripting/LLM use.

Examples:
  wi-impl ad find list
  wi-impl ad find --category Sandbox --env acme-dev --llm
  wi-impl ad find pick _lookupDCIN --open
  wi-impl ad find "documents helper" --limit 30
  wi-impl ad find --describe fetch value from json path --category Helpers --llm
  wi-impl ad find _lookupDCIN --refresh --llm

Errors: AD_INDEX_FETCH_FAILED (the category listing failed while building the
index; details {path, status}).

Notes: the index is cached (7 days). Methods wi-impl wrote are marked, and a
method whose V2 read answers METHOD_NOT_FOUND (deleted) drops out of the
cached index at once; --refresh rebuilds everything.
