wi-impl ad find <query>  :->  Find methods by name, alias or uuid; returns uuid (for show/save/test) and apiUuid (what callers reference)
wi-impl ad find  :->  List all service categories with method counts from the local method index (every category; to list one category's methods use --category <name|id>)
wi-impl ad find list  :->  Explicitly list all service categories with method counts
wi-impl ad find pick  :->  Open an interactive fzf picker to quickly select a method
wi-impl ad find pick <query>  :->  Open fzf picker with an initial query prefilled
wi-impl ad find pick <query> --open  :->  Open the selected method URL in browser after picker selection
wi-impl ad find --describe <words>  :->  Search method summaries/descriptions for the words ("does a method for X exist?")
wi-impl ad find --category <name|id|uuid>  :->  List the methods in a category (name prefix, chain-category id or uuid): data.methods + totalMethods, capped at --limit
wi-impl ad find <query> --category <name|id|uuid>  :->  Only search categories whose name starts with it (or whose id/uuid it is)
wi-impl ad find <query> --fields <a,b|all>  :->  Pick row fields, or all for every index field
wi-impl ad find <query> --limit <N>  :->  Return only the top N ranked matches (totalMatches = all matches)
wi-impl ad find <query> --refresh  :->  Rebuild the index from AD APIs before searching
wi-impl ad find <query> --raw  :->  Include the raw cached index (capped at --limit rows; scoped by --category) in the command output
