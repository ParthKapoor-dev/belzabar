belz ad find <query>  :->  Find methods by name, alias or uuid; returns uuid (for show/save/test) and apiUuid (what callers reference)
belz ad find  :->  List all service categories with method counts from the local method index (every category; to list one category's methods use --category <name|id>)
belz ad find list  :->  Explicitly list all service categories with method counts
belz ad find pick  :->  Open an interactive fzf picker to quickly select a method
belz ad find pick <query>  :->  Open fzf picker with an initial query prefilled
belz ad find pick <query> --open  :->  Open the selected method URL in browser after picker selection
belz ad find --describe <words>  :->  Search method summaries/descriptions for the words ("does a method for X exist?")
belz ad find --category <name|id|uuid>  :->  List the methods in a category (name prefix, chain-category id or uuid): data.methods + totalMethods, capped at --limit
belz ad find <query> --category <name|id|uuid>  :->  Only search categories whose name starts with it (or whose id/uuid it is)
belz ad find <query> --fields <a,b|all>  :->  Pick row fields, or all for every index field
belz ad find <query> --limit <N>  :->  Return only the top N ranked matches (totalMatches = all matches)
belz ad find <query> --refresh  :->  Rebuild the index from AD APIs before searching
belz ad find <query> --raw  :->  Include the raw cached index (capped at --limit rows; scoped by --category) in the command output
