Usage: wi-impl ad save-suite <UUID> --name <NAME> [flags]

Capture and save a regression test suite for a method.
Stores input values for repeated use with 'wi-impl ad run-suites'. The suite
records the env it was saved on; run-suites refuses to replay it elsewhere.
The method is fetched first to check the uuid. The suite is written to
suites/<NAME>.spec.json under the current directory, so NAME may contain only
letters, digits, '.', '_' and '-'.

Arguments:
  <UUID>              The UUID of the method to save a test suite for.

Flags:
  --name <NAME>       Name for this test suite, e.g. 'smoke-test-login'. (required)
  --inputs <FILE>     Path to a JSON file of input values. Prompts interactively if omitted
                      (required with --llm).
  --help, -h          Show this help message.

Global Flags:
  --env <name>        Set active environment (default: WI_IMPL_ENV, else defaultEnv, else the only env).
                      Any env from `wi-impl envs` (configured in ~/.wi-impl/config.json).
  --llm               Output structured JSON envelope for scripting/LLM use.

Examples:
  wi-impl ad save-suite 123e4567-e89b-12d3-a456-426614174000 --name smoke-test-login
  wi-impl ad save-suite 123e4567-e89b-12d3-a456-426614174000 --name smoke-test-login --inputs ./inputs.json
