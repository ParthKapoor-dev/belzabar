wi-impl rd copy <id> --from-env <source> --env <target> --yes  :->  Copy a report to another env as a new report (datasource mapped by category + method name)
wi-impl rd copy <id> --from-env <source> --env <target> --into <id> --yes  :->  Overwrite an existing target report instead (backup, conflict check, read-back)
wi-impl rd copy <id> --from-env <source> --env <target> --dry-run  :->  Resolve the datasource on the target and show the plan; write nothing
wi-impl rd copy <id> --from-env <source> --env <target> --title <text> --exact  :->  Rename on the target; also copy the display settings (runs the source report once)
