Usage: wi-impl rd save <id> --spec <file> --env <env> [flags]

Replace a report's definition with a spec file: export it, edit the file, save
it back. Report Designer keeps no history and last write wins, so belz:
  1. shows what changes (title, datasource, columns, filters, summaries);
  2. saves the current definition to ~/.wi-impl/rd/backups/<env>/ first (save that
     file back to undo);
  3. refuses (RD_CONFLICT) if the report changed since it was read;
  4. reads the result back and compares it with the spec (RD_VERIFY_FAILED).

Arguments:
  <id>                Report id (32 hex) or a Report Designer URL.

Flags:
  --spec <file>       The new definition (JSON spec). Required.
  --dry-run           Show the changes; write nothing.
  --yes, -y           Skip the confirmation prompt (required with --llm).
  --help, -h          Show this help message.

A save runs the report once to read its summaryPosition / filterConfig (only
that call returns them): a spec without them keeps the current ones. --dry-run
does not run it, so it does not list changes to those two. A spec equal to the
saved definition writes nothing.

Examples:
  wi-impl rd export 0123456789abcdef0123456789abcdef -o r.json
  wi-impl rd save 0123456789abcdef0123456789abcdef --spec r.json --env dev --dry-run
  wi-impl rd save 0123456789abcdef0123456789abcdef --spec r.json --env dev --yes
