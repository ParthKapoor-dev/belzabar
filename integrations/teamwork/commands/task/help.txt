Usage: wi-impl tw task <TASK_ID|URL> [flags]

Fetch a Teamwork task by ID or URL, including assignees, tags, status,
workflow stage, description, comment stats, and subtasks.

Arguments:
  <TASK_ID|URL>         Numeric task ID or full Teamwork task URL.

Flags:
  --help, -h            Show this help message.

Global Flags:
  --llm                 Output structured JSON envelope for scripting/LLM use.

Examples:
  wi-impl tw task 26917411
  wi-impl tw task https://<company>.teamwork.com/app/tasks/26917411
  wi-impl tw task 26917411 --llm
