Usage: belz envs [flags]

List all configured environments (name, project, base URL) and show which
one is active. Local only: no network call, and the envelope carries no
meta.env. With several environments and no default, none is active
(active: null) and env-aware commands fail with ENV_NOT_SELECTED until you
pass --env. Use --env <name> to choose the environment for any command.

Flags:
  --help, -h          Show this help message.

Global Flags:
  --env <name>        Mark this environment as active in the listing.
                      (default: BELZ_ENV, else config defaultEnv, else the
                      only configured env; otherwise none is active)
  --llm               Output structured JSON envelope for scripting/LLM use.

Examples:
  belz envs
  belz envs --env qa
  belz ad show <uuid> --env qa
