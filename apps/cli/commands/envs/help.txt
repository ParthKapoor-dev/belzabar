Usage: belz envs [flags]

List all configured environments and show which one is active.
Use --env <name> to switch environments for any command.

Flags:
  --help, -h          Show this help message.

Global Flags:
  --env <name>        Mark this environment as active in the listing.
                      (default: BELZ_ENV, else config defaultEnv, else the
                      only configured env; otherwise none is active)
  --llm               Output structured JSON envelope for scripting/LLM use.

Examples:
  belz envs
  belz envs --env qa
  belz ad show <uuid> --env qa
