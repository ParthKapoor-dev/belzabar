wi-impl update  :->  Update wi-impl: a binary install downloads, verifies and swaps in the latest release (or the pinned one); a source install fast-forwards its checkout and rebuilds
wi-impl update --check  :->  Check whether an update is available
wi-impl update --force  :->  Reinstall even when up to date (-f); never resets or discards local source changes
wi-impl update --rollback  :->  Binary install: restore the previous binary kept from the last update
