Usage: wi-impl config <subcommand> [flags]

Manage wi-impl credentials and environment configuration.

Subcommands:
  get             Show URL, user, password status, and whether a session token is cached (never the token).
  token           Print the raw Bearer token to stdout (for scripting/clipboard).
                  Re-logs in when there is no session or the token has expired.
    --refresh     Force a fresh login before printing the token.
  edit            Interactively add, edit, or remove credentials in ~/.wi-impl/config.json,
                  or set the default environment ("defaultEnv").

Flags:
  --help, -h      Show this help message.

Global Flags:
  --env <name>    Set active environment (default: WI_IMPL_ENV, else config defaultEnv,
                  else the only configured env).
                  Any env from `wi-impl envs` (configured in ~/.wi-impl/config.json).
  --llm           Output structured JSON envelope for scripting/LLM use.

Examples:
  wi-impl config get
  wi-impl config get --env qa
  wi-impl config token
  wi-impl config token --env qa --llm
  wi-impl config token --refresh
  wi-impl config edit
