Usage: belz config <subcommand> [flags]

Manage belz credentials and environment configuration.

Subcommands:
  get             Show URL, user, password status, and whether a session token is cached (never the token).
  token           Print the raw Bearer token to stdout (for scripting/clipboard).
                  Re-logs in when there is no session or the token has expired.
    --refresh     Force a fresh login before printing the token.
  edit            Interactively add, edit, or remove credentials in ~/.belz/config.json,
                  or set the default environment ("defaultEnv").

Flags:
  --help, -h      Show this help message.

Global Flags:
  --env <name>    Set active environment (default: BELZ_ENV, else config defaultEnv,
                  else the only configured env).
                  Any env from `belz envs` (configured in ~/.belz/config.json).
  --llm           Output structured JSON envelope for scripting/LLM use.

Examples:
  belz config get
  belz config get --env qa
  belz config token
  belz config token --env qa --llm
  belz config token --refresh
  belz config edit
